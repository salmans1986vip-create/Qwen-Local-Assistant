# 🤖 مساعد Qwen المحلي | Qwen Local AI Assistant

## معلومات المشروع

**اسم الطالب:** سلمان بن سالم واصل الحربي
**الجامعة:** جامعة الأمير مساعد بن عبدالرحمن
**البرنامج:** دبلوم الذكاء الاصطناعي التوليدي
**نوع المشروع:** تطبيق عملي في الذكاء الاصطناعي التوليدي

## 1. نبذة عن المشروع

مساعد Qwen المحلي هو تطبيق ذكاء اصطناعي تم تطويره باستخدام لغة Python، ويعمل محليًا على جهاز الكمبيوتر باستخدام نموذج Qwen من خلال Ollama.

يهدف المشروع إلى مساعدة الطلاب في دراسة المحاضرات والمستندات التعليمية، من خلال قراءة ملفات PDF والإجابة عن الأسئلة بالاعتماد على المعلومات الموجودة فيها.

يستخدم التطبيق تقنية **Retrieval-Augmented Generation (RAG)**، التي تجمع بين البحث داخل المستندات وتوليد الإجابات باستخدام النموذج اللغوي.

## 2. أهداف المشروع

* بناء مساعد ذكاء اصطناعي يعمل محليًا.
* دعم المحادثة باللغة العربية.
* قراءة عدة ملفات PDF.
* البحث عن المعلومات باستخدام البحث الدلالي.
* تقديم إجابات مرتبطة بمحتوى المحاضرات.
* عرض اسم الملف ورقم الصفحة والمقاطع المسترجعة.
* حفظ سجل المحادثات وإمكانية الرجوع إليها.

## 3. التقنيات المستخدمة

| التقنية     | الوظيفة                                 |
| ----------- | --------------------------------------- |
| Python      | تطوير التطبيق                           |
| Qwen 3.5 9B | النموذج اللغوي                          |
| Ollama      | تشغيل النماذج محليًا                    |
| LangChain   | ربط النموذج بقوالب المحادثة             |
| Streamlit   | إنشاء واجهة المستخدم                    |
| PyMuPDF     | استخراج النصوص من PDF                   |
| BGE-M3      | تحويل النصوص والأسئلة إلى متجهات دلالية |
| RAG         | استرجاع المعلومات لدعم الإجابات         |
| JSON        | حفظ المحادثات محليًا                    |

## 4. آلية عمل المساعد

عند رفع ملف PDF، يستخرج التطبيق النصوص ويقسمها إلى مقاطع، مع الاحتفاظ برقم الصفحة.

بعد ذلك يحول المقاطع إلى متجهات دلالية باستخدام BGE-M3.

وعندما يطرح المستخدم سؤالًا، يبحث التطبيق عن المقاطع الأكثر ارتباطًا بالسؤال باستخدام تشابه جيب التمام (Cosine Similarity)، ثم يرسل المقاطع إلى نموذج Qwen لتوليد الإجابة.

يمكن للمستخدم مراجعة المقاطع المسترجعة وأرقام صفحاتها للتحقق من المعلومات.

## 5. طريقة التشغيل

يجب تثبيت Python وOllama على الجهاز.

تثبيت المكتبات:

```bash
pip install streamlit pymupdf langchain-ollama langchain-core
```

تحميل النماذج باستخدام Ollama:

```bash
ollama pull qwen3.5:9b-q4_K_M
ollama pull bge-m3
```

تشغيل التطبيق من مجلد المشروع:

```bash
streamlit run gui_chat_rag.py
```

ثم فتح الرابط المحلي الذي يظهر في Terminal.

## 6. الملف البرمجي الأساسي

**gui_chat_rag.py**

يحتوي الملف على الكود الأساسي للتطبيق، بما يشمل واجهة المستخدم، وإدارة المحادثات، واستخراج النصوص، والفهرسة الدلالية، واسترجاع المقاطع، وتوليد الإجابات.

## 7. حالة المشروع وحدوده

المشروع نموذج أولي يعمل محليًا، وقد خضع لتجارب عملية على ملفات محاضرات PDF.

قد تختلف دقة الإجابات حسب جودة النص المستخرج والمقاطع المسترجعة. كما أن ملفات PDF المكونة من صور دون نص قابل للاستخراج لا تدعمها النسخة الحالية مباشرة.

المشروع لا يعمل كتطبيق مستضاف على GitHub؛ إذ يتطلب تشغيل Ollama والنماذج اللازمة على جهاز المستخدم.

## 8. التطوير المستقبلي

يمكن تطوير المشروع مستقبلًا لدعم الصور والمستندات الإضافية، وتحسين دقة البحث والاسترجاع، وتوسيع الاختبارات وتقييم جودة الإجابات.
